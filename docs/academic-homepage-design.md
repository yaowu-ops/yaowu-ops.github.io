# 吴瑶个人学术主页设计说明

## 设计定位

网站首版为中文单页响应式学术主页，服务于招生招聘、团队建设、国内外合作和研究成果展示。视觉采用白底、北大红（`#8c0000`）和深灰正文，保留充分留白，不使用照片、插画、渐变、搜索框或大面积卡片阴影。

## 页面结构

1. 顶部身份信息与导航
2. 首页研究定位
3. 个人简介、教育和工作经历
4. 四个研究方向
5. 团队成员
6. 24 篇一作/通讯作者代表性成果与主题筛选
7. 学术影响、荣誉和兼职
8. 加入我们
9. 相关学术链接

## 内容维护

- 论文数据维护在 `js/publications.js`，每条记录包含作者、题目、期刊、年份、卷页/文章号、DOI 和主题分类。
- 团队成员维护在 `js/members.js`。团队组建阶段只显示说明，不虚构成员。
- 新成员加入时，在 `members` 数组中新增对象即可；头像为可选项，未提供时不要添加占位图。
- 更新引用指标时，同时修改页面的更新时间说明。
- 不在前端动态抓取 Google Scholar 数据。

## 部署

保持 `index.html`、`css/`、`js/` 和 `docs/` 的相对路径，直接部署到 GitHub Pages 即可。英文版未来可新增 `/en/`，无需重构中文页面。
